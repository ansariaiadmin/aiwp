## 🔧 پرووایدرها — Provider Setup — راهنمای همون‌جا

### 🤖 AI Provider — پرووایدر هوش مصنوعی

**چیه؟** شرکتی که هوش مصنوعی می‌ده — مثل OpenAI که ChatGPT می‌ده — AiWp با این افزونه می‌سازه

**چرا نیازه؟** بدون AI، AiWp نمی‌تونه افزونه بسازه — ولی mock هم می‌شه (بدون AI واقعی، برای تست)

**گزینه‌ها:**
- **openai** — GPT-4.1 — بهترین برای کدنویسی — https://platform.openai.com/api-keys → Create new secret key → sk-proj-...
- **anthropic** — Claude Sonnet 4.5 — بهترین برای تحلیل — https://console.anthropic.com/ → API Keys → sk-ant-...
- **google** — Gemini 2.5 Pro — رایگان تا حدی — https://aistudio.google.com/app/apikey
- **openrouter** — هر مدلی — https://openrouter.ai/keys
- **mock** — بدون AI واقعی — پیام‌ها تو لاگ — برای تست عالی

**کجا پیدا کنم؟** همون لینک بالا — ثبت‌نام → API Keys → Create → کپی

**مثال:** `sk-proj-abc123...` یا `sk-ant-api03-...`

**بعداً چطور عوض کنم؟** `/admin/settings/ai-provider` → پرووایدر جدید → کلید جدید → تست

### 📱 SMS Panel — پنل پیامکی

**چیه؟** سرویسی که پیامک می‌فرسته — وقتی مشتری ثبت‌نام می‌کنه، کد تایید با پیامک می‌ره — یا لایسنس با پیامک

**چرا نیازه؟** برای ارسال کد تایید، لایسنس، ناتیفیکیشن — ولی mock هم می‌شه (پیامک‌ها تو لاگ)

**گزینه‌ها:**
- **ghasedak** — قاصدک — ایرانی، ارزون، API ساده — https://ghasedak.me/ → ثبت‌نام → داشبورد → API Key → رایگان ۵۰ پیامک
- **kavenegar** — کاوه‌نگار — قدیمی، پایدار — https://kavenegar.com/ → ثبت‌نام → تنظیمات → API Key
- **melipayamak** — ملی‌پیامک — https://melipayamak.com/
- **mock** — بدون پیامک واقعی — پیامک‌ها تو فایل log — برای تست

**کجا پیدا کنم؟** برو سایت پنل → ثبت‌نام → شماره موبایل تایید → داشبورد → بخش API یا تنظیمات → کلید API رو کپی

**شماره فرستنده چیه؟** شماره‌ای که پیامک ازش می‌ره — مثل 10008566 یا 500012345 — از پنل → شماره‌ها → شماره اختصاصی‌ات

**مثال API Key:** `abc123def456...` — ۳۲ کاراکتر

**مثال Sender:** `10008566`

**تست:** جادوگر بعد از وارد کردن کلید، تست می‌کنه — "اتصال به ghasedak — اوکی"

**بعداً چطور عوض کنم؟** `/admin/settings/sms-gateway` → پنل جدید → کلید → تست

### 📧 Email Provider — پرووایدر ایمیل

**چیه؟** برای ارسال ایمیل تایید، فاکتور، بازیابی رمز

**گزینه‌ها:**
- **smtp** — SMTP معمولی — Gmail یا هاست خودت — ارزون
- **resend** — Resend.com — مدرن، API ساده — https://resend.com/ → رایگان ۳۰۰۰ ایمیل/ماه
- **mock** — بدون ایمیل واقعی — ایمیل‌ها تو لاگ

**SMTP چیه؟** پروتکل ارسال ایمیل — هر ایمیلی SMTP داره — مثل smtp.gmail.com

**Gmail چطور؟**
1. برو myaccount.google.com → Security → 2-Step Verification روشن کن
2. Security → App Passwords → Create → اسم بده (AiWp) → ۱۶ کاراکتر می‌ده
3. اون ۱۶ کاراکتر رمز SMTP می‌شه

**مثال:**
- Host: `smtp.gmail.com`
- Port: `587` (معمولاً 587 برای TLS، 465 برای SSL)
- User: `you@gmail.com`
- Pass: `abcd efgh ijkl mnop` (۱۶ کاراکتر App Password)

**بعداً چطور عوض کنم؟** `.env` → SMTP_... → `docker compose restart`

## 🔔 سیستم ناتیفیکیشن — Notification System — سقف 10/10

**چیه؟** وقتی اتفاقی می‌افته (ثبت‌نام جدید، پرداخت، خطا، فروش) بهت خبر می‌ده — چند کانال:

**کانال‌ها:**
1. **In-App (داخل برنامه)** — همیشه روشن — نوتیف‌ها تو داشبورد می‌بینی — مثل نوتیف اینستاگرام
2. **Email** — ایمیل می‌ره — وقتی پرداخت جدید میاد
3. **SMS** — پیامک می‌ره — برای اتفاقات مهم
4. **Telegram** — ربات تلگرام — برای ادمین — وقتی فروش جدید یا خطا میاد تو تلگرام پیام می‌ده

**چطور کار می‌کنه؟**
- جادوگر می‌پرسه: "ایمیل ناتیف روشن باشه؟" → y → از همون SMTP که دادی استفاده می‌کنه
- "پیامک ناتیف روشن باشه؟" → y → از همون پنل پیامکی استفاده می‌کنه
- "ربات تلگرام می‌خوای؟" → y → توکن + Chat ID می‌پرسه

**ربات تلگرام چطور بسازم؟ — ۱ دقیقه:**
1. برو تلگرام → سرچ کن `@BotFather` (تیک آبی داره)
2. `/newbot` بزن → اسم ربات بده (مثل AiWp Notif) → یوزرنیم بده (مثل aiwp_notif_bot — باید bot داشته باشه)
3. توکن می‌ده — مثل `123456789:ABCdefGHIjklMNOpqrSTUvwxYZ` — کپی کن
4. ربات رو استارت کن → یه پیام بده (سلام)
5. برو تو مرورگر: `https://api.telegram.org/bot<TOKEN>/getUpdates` — جای <TOKEN> توکنت رو بذار
6. تو JSON، `chat` → `id` رو ببین — مثل `123456789` — اون Chat ID می‌شه

**مثال:**
- Bot Token: `123456789:ABCdefGHIjklMNOpqrSTUvwxYZ`
- Chat ID: `123456789`

**تست:** جادوگر تست می‌کنه — پیام تست می‌فرسته به تلگرامت

**بعداً چطور عوض کنم؟** `.env` → TELEGRAM_BOT_TOKEN + TELEGRAM_CHAT_ID → restart

**کد ناتیفیکیشن کجاست؟** `platform/src/lib/notification/service.ts` — سقف 10/10 — multi-channel

## 🆘 عیب‌یابی — پشتیبانی صفر — همه چی همینجاست!

**AI کار نمی‌کنه؟**
→ برو `/admin/settings/ai-provider` → کلید چک کن → از https://platform.openai.com/api-keys کلید جدید بگیر → تست کن
→ اگر mock بود: همونجا پرووایدر واقعی اضافه کن

**SMS نمی‌ره؟**
→ `/admin/settings/sms-gateway` → پنل چک کن → API Key چک کن → https://ghasedak.me/ → داشبورد → API
→ لاگ ببین: `./logs.sh` → دنبال SMS بگرد
→ اگر mock بود: پیامک‌ها تو لاگ هست — `docker compose logs | grep SMS`

**ایمیل نمی‌ره؟**
→ `.env` → SMTP_HOST, SMTP_USER, SMTP_PASS چک کن
→ Gmail App Password بساز: myaccount.google.com → Security → App Passwords
→ `./logs.sh` → دنبال Email بگرد

**تلگرام نمی‌ره؟**
→ `.env` → TELEGRAM_BOT_TOKEN + CHAT_ID چک کن
→ تست: `curl https://api.telegram.org/bot<TOKEN>/getMe` — باید ok:true بده
→ ربات رو استارت کردی؟ — تو تلگرام به رباتت پیام بده

**پورت اشغال؟**
→ `./stop.sh` + `docker compose down` + `./start.sh` — مثل دو نفر روی یک صندلی

**.env خراب؟**
→ `rm .env` + `./install.sh` — دوباره می‌سازه — همه چی رو دوباره می‌پرسه با راهنما

**سرویس بالا نمی‌آد؟**
→ `./logs.sh` → خطا رو ببین → معمولاً رمز دیتابیس یا پورت

**ناتیفیکیشن نمی‌ره؟**
→ `.env` → NOTIF_EMAIL, NOTIF_SMS, NOTIF_TELEGRAM چک کن — باید yes باشه
→ `platform/src/lib/notification/service.ts` → لاگ
