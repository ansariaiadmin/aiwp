## 🎯 AiWp چیه؟ به زبان مامان بزرگ:

فرض کن می‌خوای یک افزونه وردپرس بسازی — مثلا افزونه‌ای که سفارشات فروشگاهت رو هر روز SMS کنه.

**قبلاً:** باید ۶ ماه PHP یاد می‌گرفتی، امنیت، دیتابیس، تنظیمات — سخت!

**الان با AiWp:** مثل لگو — قطعات رو کنار هم می‌چینی — ۱ دقیقه‌ای افزونه آماده!

- **قطعات لگو:** تنظیمات، دیتابیس، API، SMS، لایسنس، زمان‌بندی — ۹ تا قطعه
- **چطور؟** یا با هوش مصنوعی بگی "من SMS می‌خوام" — خودش می‌چینه — یا خودت drag-drop کنی
- **خروجی:** یک فایل ZIP — آپلود تو وردپرس — تمام!

## 🚀 جادوگر نصب — فقط ۳ قدم — مثل نصب واتساپ!

### قدم صفر: چی لازم داری؟ (۳۰ ثانیه)

**یک کامپیوتر با اینترنت — همین!**

- **ویندوز:** Windows 10 یا 11
- **مک:** MacOS
- **لینوکس:** Ubuntu

**Docker چیه؟** نگران نباش — جادوگر خودش چک می‌کنه، اگر نباشه بهت می‌گه چطور نصب کنی — مثل نصب واتساپ، ۲ دقیقه.

---

### قدم ۱: دانلود — مثل دانلود فیلم (۳۰ ثانیه)

**روش ۱ — با Git (اگر بلدی):**
```bash
git clone https://github.com/ansariaiadmin/aiwp.git
cd aiwp
```

**روش ۲ — بدون Git (برای همه):**
1. برو به https://github.com/ansariaiadmin/aiwp/releases/tag/v2.0.0
2. روی `Source code (zip)` کلیک کن — دانلود می‌شه
3. فایل zip رو باز کن (Extract) — وارد پوشه `aiwp` شو

**تمام!** الان تو پوشه aiwp هستی.

### قدم ۳: استفاده — مرورگر رو باز کن (۱۰ ثانیه)

مرورگر (Chrome, Firefox) رو باز کن، برو به:
```
http://localhost:3000
```

**ورود:**
- ایمیل: `admin@aiwp.dev`
- رمز: `Admin@123`

**حالا کجایی؟**
- داشبورد AiWp — کارخانه افزونه
- برو به `/spec-builder` — جادوگر ساخت افزونه با drag-drop + هوش مصنوعی — سقف 10/10!

**مثال — ساخت افزونه SMS در 1 دقیقه:**
1. برو به `http://localhost:3000/spec-builder`
2. تو بخش AI بنویس: "من یک افزونه می‌خوام سفارشات ووکامرس رو هر روز SMS کنه"
3. کلیک "Generate with AI" — خودش ماژول‌های SMS + cron + db-table رو انتخاب می‌کنه
4. کلیک "Generate Spec JSON" — پیش‌نمایش JSON
5. کلیک "Build ZIP" — دانلود ZIP افزونه!
6. برو به وردپرس → افزونه‌ها → افزودن → بارگذاری ZIP → فعال کن — تمام!

## 🔄 آپدیت — وقتی نسخه جدید اومد (۳۰ ثانیه)

هر وقت تو گروه گفتن نسخه جدید اومده:

```bash
./update.sh
```

**جادوگر آپدیت چی کار می‌کنه؟**
1. بکاپ خودکار می‌گیره به `backups/20240101-120000/` — اگر خراب شد برمی‌گرده
2. آخرین کد رو از GitHub می‌گیره
3. دوباره می‌سازه و اجرا می‌کنه
4. سلامت چک می‌کنه — اگر خراب بود می‌گه چطور برگردی

**اگر آپدیت خراب شد:**
```bash
cp backups/20240101-120000/.env .env
docker compose up -d
```

## 🛠️ دستورات روزانه — مثل کنترل تلویزیون!

| دستور | به زبان ساده | کی استفاده کنی؟ |
|-------|-------------|----------------|
| `./install.sh` | نصب اولیه — فقط بار اول | بار اول که دانلود کردی |
| `./update.sh` | آپدیت به آخرین نسخه | وقتی گفتن نسخه جدید اومده |
| `./start.sh` | روشن کردن | وقتی خاموشه و می‌خوای روشن کنی |
| `./stop.sh` | خاموش کردن | وقتی می‌خوای خاموش کنی |
| `./status.sh` | ببین روشنه یا نه + سلامت | هر روز — ببین همه چی اوکیه؟ |
| `./logs.sh` | ببین چی می‌گذره — لاگ | وقتی خطا داره |
| `./backup.sh` | بکاپ بگیر — کپی امن | هفته‌ای یک بار |

**مثال روزانه:**
```bash
./status.sh   # صبح — ببین روشنه؟
# کار کن با AiWp...
./logs.sh     # اگر خطا دیدی
./stop.sh     # شب — خاموش
```

## 🆘 عیب‌یابی — اگر چیزی خراب شد — به زبان مامان بزرگ!

### مشکل: "پورت اشغال است" — Port already in use

**یعنی چی؟** یک برنامه دیگه داره از پورت 3000 استفاده می‌کنه — مثل دو نفر که می‌خوان روی یک صندلی بشینن.

**حل — فوق ساده:**
```bash
./stop.sh
docker compose down
./start.sh
```

اگر بازم نشد:
```bash
# ببین کی نشسته روی صندلی:
sudo lsof -i :3000
# بعد بکشش:
kill -9 <PID>
./start.sh
```

### مشکل: "Docker نصب نیست"

**یعنی چی؟** جعبه جادویی که برنامه رو اجرا می‌کنه نصب نیست.

**حل:**
- **ویندوز/مک:** برو به https://docs.docker.com/get-docker/ — Docker Desktop دانلود کن — نصب کن — تمام!
- **لینوکس:** 
```bash
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
# دوباره لاگین کن
```

### مشکل: ".env خراب"

**یعنی چی؟** فایل رمزها خراب شده.

**حل — ۱۰ ثانیه:**
```bash
rm .env
cp .env.example .env
./install.sh
```

### مشکل: "سرویس بالا نمی‌آید"

**حل:**
```bash
./logs.sh
# لاگ رو بخون — معمولا می‌گه رمز یا دیتابیس مشکل داره
./backup.sh
./stop.sh
./start.sh
```

اگر بازم نشد — ایشو باز کن: https://github.com/ansariaiadmin/aiwp/issues — ما کمک می‌کنیم!
