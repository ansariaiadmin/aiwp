Real-time site health scoring, backup freshness alerts, scheduled email digests and a REST status API - zero configuration needed.

This plugin was generated by the AnsariAi WordPress Plugin Factory.

== Installation ==

1. Upload the plugin ZIP via Plugins → Add New → Upload Plugin, or extract
   it into `wp-content/plugins/`.
2. Activate the plugin through the "Plugins" screen in WordPress.
3. Configure the plugin under its settings screen.

== Frequently Asked Questions ==

= Does this plugin work with WooCommerce High-Performance Order Storage (HPOS)? =

Yes. This plugin declares compatibility with `custom_order_tables` and
`cart_checkout_blocks` and only reads/writes WooCommerce orders through
`wc_get_orders()` / `WC_Order` CRUD methods.
